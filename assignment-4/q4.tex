\subsection*{Solution}

Let:
\[
v_1 = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix}, \quad v_2 = \frac{1}{\sqrt{3}} \begin{pmatrix} 1 \\ 1 \\ -1 \end{pmatrix}
\]

For orthonormal, we need:
\begin{enumerate}
\item $\|v_1\| = 1$
\item $\|v_2\| = 1$
\item $v_1 \cdot v_2 = 0$
\end{enumerate}

\textbf{Check $\|v_1\|$:}
\[
\|v_1\|^2 = \frac{1}{2}(1^2 + 0^2 + 1^2) = \frac{1}{2}(2) = 1
\]
So $\|v_1\| = 1$. Good.

\textbf{Check $\|v_2\|$:}
\[
\|v_2\|^2 = \frac{1}{3}(1^2 + 1^2 + (-1)^2) = \frac{1}{3}(3) = 1
\]
So $\|v_2\| = 1$. Good.

\textbf{Check $v_1 \cdot v_2$:}
\[
v_1 \cdot v_2 = \frac{1}{\sqrt{2}} \cdot \frac{1}{\sqrt{3}} \left[ (1)(1) + (0)(1) + (1)(-1) \right]
\]
\[
= \frac{1}{\sqrt{6}} (1 + 0 - 1)
\]
\[
= \frac{1}{\sqrt{6}} (0) = 0
\]

Since:
\begin{itemize}
\item $\|v_1\| = 1$
\item $\|v_2\| = 1$
\item $v_1 \cdot v_2 = 0$
\end{itemize}

The set is already orthonormal. No normalization needed.
