\subsection*{Solution}

The inner product is defined as:
\[
\langle p, q \rangle = p(-1)q(-1) + p(0)q(0) + p(1)q(1)
\]

\textbf{Part (a): Find $\langle 1, x \rangle$}

Let $p(x) = 1$ and $q(x) = x$.

Evaluate at each point:
\begin{align*}
p(-1) &= 1, \quad q(-1) = -1 \\
p(0) &= 1, \quad q(0) = 0 \\
p(1) &= 1, \quad q(1) = 1
\end{align*}

Calculate:
\[
\langle 1, x \rangle = (1)(-1) + (1)(0) + (1)(1) = -1 + 0 + 1 = 0
\]

\textbf{Part (b): Find $\langle x, x^2 \rangle$}

Let $p(x) = x$ and $q(x) = x^2$.

Evaluate at each point:
\begin{align*}
p(-1) &= -1, \quad q(-1) = 1 \\
p(0) &= 0, \quad q(0) = 0 \\
p(1) &= 1, \quad q(1) = 1
\end{align*}

Calculate:
\[
\langle x, x^2 \rangle = (-1)(1) + (0)(0) + (1)(1) = -1 + 0 + 1 = 0
\]

Therefore:
\[
\langle 1, x \rangle = 0 \quad \text{and} \quad \langle x, x^2 \rangle = 0
\]
